# Maharaja Palace — เว็บร้านอาหารอินเดีย (ดีไซน์ใหม่)

## วิธีใช้
1. คัดลอกทุกไฟล์ในชุดนี้ไปทับโฟลเดอร์โปรเจกต์เดิม (โฟลเดอร์ที่มี `restaurant.db` อยู่) — **ไม่ต้องลบหรือแก้ฐานข้อมูล ข้อมูลเดิมอยู่ครบ**
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

## เปลี่ยนโลโก้
- แอดมิน > ⚙️ ตั้งค่า > โลโก้ร้าน > อัปโหลด (แนะนำ) หรือวางไฟล์ `logo.png` ไว้ข้าง `app.py`
- ย้ายโลโก้ไปมุมซ้ายบน: `config.py` → `LOGO_SIDE = "left"`

## ลิงก์โซเชียลที่ฟุตเตอร์
แอดมิน > ⚙️ ตั้งค่า > ลิงก์โซเชียล (เว้นว่าง = ไม่แสดงไอคอนนั้น)

## รหัสแอดมิน / QR
ดูที่ `config.py` (รหัสเริ่มต้น `admin1234` ควรเปลี่ยนผ่านตัวแปรแวดล้อม `ADMIN_PASSWORD`)
เข้าแอดมินได้จากปุ่ม “🔐 สำหรับพนักงาน” ท้ายหน้าเว็บ

## ทดสอบ
`python -m unittest discover -s tests -v`

## การชำระเงิน (ใหม่)
- ลูกค้าเลือกได้ 2 แบบ: **โอนเงิน/QR (ต้องแนบสลิป)** หรือ **เงินสด** (ที่ร้าน/ปลายทาง)
- แอดมิน > ออเดอร์: ออเดอร์ที่รอตรวจเปิดไว้ให้เลย เห็นรูปสลิป ยอดที่ต้องได้รับ และปุ่มยืนยัน/ปฏิเสธ
- ลูกค้าแนบสลิปทีหลังได้ที่หน้า "ติดตามออเดอร์" (ก่อนร้านยืนยัน)
- สลิปเก็บในตาราง `slips` ของ `restaurant.db` (ไม่ต้องตั้งค่าเพิ่ม ระบบเพิ่มตารางให้เองเมื่อรัน)

## ใบเสร็จ PDF + VAT 7% (ใหม่)
- หน้า "ติดตามออเดอร์" → ปุ่ม **ดาวน์โหลดใบเสร็จ (PDF)** (ขนาด A5, มีตราประทับ PAID, แยกราคาก่อน VAT และ VAT 7%)
- ราคาในเว็บถือเป็นราคา **รวม VAT แล้ว** ยอดที่ลูกค้าจ่ายไม่เปลี่ยน ใบเสร็จแค่แยกให้เห็น (ปรับอัตราที่ `VAT_RATE` ใน `config.py`)
- ใส่เลขประจำตัวผู้เสียภาษีของร้านที่ `TAX_ID` ใน `config.py` (หรือตัวแปรแวดล้อม `TAX_ID`) จะแสดงบนหัวใบเสร็จ
- ที่อยู่/เบอร์/เวลาเปิดบนใบเสร็จดึงจากแอดมิน > ตั้งค่า · ต้องติดตั้ง `pip install -r requirements.txt` (เพิ่ม reportlab)
- ฟอนต์ภาษาไทยของ PDF อยู่ที่ `fonts/` (Loma, GPL-2+ with Font exception) ห้ามลบโฟลเดอร์นี้

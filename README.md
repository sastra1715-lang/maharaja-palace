# Maharaja Palace — เว็บร้านอาหารอินเดีย (ดีไซน์ใหม่)

## วิธีใช้
1. คัดลอกทุกไฟล์ในชุดนี้ไปทับโฟลเดอร์โปรเจกต์เดิม (โฟลเดอร์ที่มี `restaurant.db` อยู่) — **ไม่ต้องลบหรือแก้ฐานข้อมูล ข้อมูลเดิมอยู่ครบ**
2. `pip install -r requirements.txt`
3. python -m streamlit run app.py หรือ streamlit run app.py
   (คำสั่งเปิดเว็บ)


## เปลี่ยนโลโก้
- แอดมิน > ⚙️ ตั้งค่า > โลโก้ร้าน > อัปโหลด (แนะนำ) หรือวางไฟล์ `logo.png` ไว้ข้าง `app.py`
- ย้ายโลโก้ไปมุมซ้ายบน: `config.py` → `LOGO_SIDE = "left"`

## ลิงก์โซเชียลที่ฟุตเตอร์
แอดมิน > ⚙️ ตั้งค่า > ลิงก์โซเชียล (เว้นว่าง = ไม่แสดงไอคอนนั้น)

## รหัสแอดมิน / QR
ดูที่ `config.py` (รหัสเริ่มต้น `admin1234` ควรเปลี่ยนผ่านตัวแปรแวดล้อม `ADMIN_PASSWORD`)
เข้าแอดมินได้จากปุ่ม “🔐 สำหรับพนักงาน” ท้ายหน้าเว็บ

## ทดสอบ
`python -m unittest discover -s tests -v`

## การชำระเงิน (ใหม่)
- ลูกค้าเลือกได้ 2 แบบ: **โอนเงิน/QR (ต้องแนบสลิป)** หรือ **เงินสด** (ที่ร้าน/ปลายทาง)
- แอดมิน > ออเดอร์: ออเดอร์ที่รอตรวจเปิดไว้ให้เลย เห็นรูปสลิป ยอดที่ต้องได้รับ และปุ่มยืนยัน/ปฏิเสธ
- ลูกค้าแนบสลิปทีหลังได้ที่หน้า "ติดตามออเดอร์" (ก่อนร้านยืนยัน)
- สลิปเก็บในตาราง `slips` ของ `restaurant.db` (ไม่ต้องตั้งค่าเพิ่ม ระบบเพิ่มตารางให้เองเมื่อรัน)

## ใบเสร็จ PDF + VAT 7% (ใหม่)
- หน้า "ติดตามออเดอร์" → ปุ่ม **ดาวน์โหลดใบเสร็จ (PDF)** (ขนาด A5, มีตราประทับ PAID, แยกราคาก่อน VAT และ VAT 7%)
- ราคาในเว็บถือเป็นราคา **รวม VAT แล้ว** ยอดที่ลูกค้าจ่ายไม่เปลี่ยน ใบเสร็จแค่แยกให้เห็น (ปรับอัตราที่ `VAT_RATE` ใน `config.py`)
- ใส่เลขประจำตัวผู้เสียภาษีของร้านที่ `TAX_ID` ใน `config.py` (หรือตัวแปรแวดล้อม `TAX_ID`) จะแสดงบนหัวใบเสร็จ
- ที่อยู่/เบอร์/เวลาเปิดบนใบเสร็จดึงจากแอดมิน > ตั้งค่า · ต้องติดตั้ง `pip install -r requirements.txt` (เพิ่ม reportlab)
- ฟอนต์ภาษาไทยของ PDF อยู่ที่ `fonts/` (Loma, GPL-2+ with Font exception) ห้ามลบโฟลเดอร์นี้

ระบบนี้เป็นเว็บสั่งอาหารและจัดการร้านอาหารอินเดีย สร้างด้วย Python (Streamlit) และเก็บข้อมูลใน SQLite (restaurant.db) แบ่งเป็น 2 ส่วนหลัก

ส่วน	ผู้ใช้	ทำอะไรได้

หลังบ้านแอดมิน	เจ้าของร้านและพนักงาน	ตรวจสลิป จัดการออเดอร์ ครัว เมนู บัญชี คูปอง ตั้งค่าร้าน
2. การติดตั้งและเริ่มใช้งาน
ติดตั้ง Python 3.9 ขึ้นไป
วางไฟล์ทั้งหมดไว้ในโฟลเดอร์โปรเจกต์ และให้ restaurant.db อยู่โฟลเดอร์เดียวกับ app.py
ถ้าไม่มี restaurant.db ระบบจะสร้างฐานข้อมูลใหม่ให้เองตอนรัน
เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วติดตั้งไลบรารี
   pip install -r requirements.txt

ไลบรารีที่ต้องใช้: streamlit (1.40 ขึ้นไป), pandas, reportlab
4. รันเว็บ

   streamlit run app.py
เบราว์เซอร์จะเปิดที่ http://localhost:8501

ข้อควรระวัง

ต้องมีโฟลเดอร์ fonts/ (ฟอนต์ Loma) สำหรับพิมพ์ภาษาไทยในใบเสร็จ PDF ห้ามลบ
ไฟล์ database.py ต้องชื่อนี้เป๊ะ ไม่มีเว้นวรรค
ถ้าเจอข้อความว่า Streamlit เก่าเกินไป ให้รัน pip install -U streamlit
3. คู่มือสำหรับลูกค้า

แถบเมนูด้านบนมี 5 หน้าหลัก ได้แก่ หน้าแรก, เมนูอาหาร, จองโต๊ะ, สมาชิก, ติดตามออเดอร์ และมีปุ่ม ตะกร้า แยกต่างหาก

3.1 หน้าแรก
แสดงแบนเนอร์ร้าน เมนูขายดี ความรู้เรื่องเครื่องเทศอินเดีย และระดับความเผ็ด
มีสถานะ เปิด/ปิดร้าน คำนวณจากเวลาเปิด-ปิดที่แอดมินตั้งไว้
3.2 เมนูอาหาร
ค้นหา พิมพ์ชื่อเมนู เช่น biryani, ไก่, มังสวิรัติ
เรียงตาม เลือกการเรียงลำดับเมนู
เฉพาะมังสวิรัติ เปิดสวิตช์เพื่อแสดงเฉพาะเมนูที่มีป้ายมังสวิรัติ
ดูหมวดหมู่ ได้แก่ ของทานเล่น, ทันดูรี, แกงอินเดีย, ข้าวและขนมปัง, ของหวานและเครื่องดื่ม
กดเพิ่มเมนูลงตะกร้า
เมนูที่สต็อกหมดจะสั่งไม่ได้
3.3 ตะกร้าและการสั่งซื้อ

เปิดหน้า ตะกร้า แล้วทำตามลำดับนี้

ขั้นที่ 1: ตรวจรายการอาหาร
ปรับจำนวนหรือลบเมนูที่ไม่ต้องการ

ขั้นที่ 2: เลือกรูปแบบการรับอาหาร

รูปแบบ	ข้อมูลที่ต้องกรอกเพิ่ม	ค่าส่ง
จัดส่ง (Delivery)	ที่อยู่จัดส่ง	50 บาท (ฟรีเมื่อยอดสูงถึง 800 บาท)
รับที่ร้าน (Pickup)	-	ไม่มี
ทานที่ร้าน (Dine-in)	หมายเลขโต๊ะ	ไม่มี

ขั้นที่ 3: ใช้ส่วนลด

เบอร์ที่เคยสั่ง กรอกเบอร์เพื่อดึงแต้มสะสมมาใช้
โค้ดส่วนลด เช่น WELCOME10 (ลด 10% เมื่อยอดถึงขั้นต่ำที่ตั้งไว้) ถ้ายอดไม่ถึงขั้นต่ำ ส่วนลดจะเป็น 0
ใช้แต้มสะสมเป็นส่วนลด ใช้ได้ไม่เกินแต้มที่มีและไม่เกินยอดหลังหักส่วนลด

ขั้นที่ 4: เลือกวิธีชำระเงิน

โอนเงิน/QR สแกน QR PromptPay ของร้าน จากนั้น แนบสลิป (PNG หรือ JPG ไม่เกิน 3MB) และกรอกเวลาที่โอนได้ (ไม่บังคับ)
เงินสด จ่ายที่ร้านหรือปลายทาง ไม่ต้องแนบสลิป

ขั้นที่ 5: กรอกข้อมูลผู้สั่ง
ชื่อผู้รับ, เบอร์โทร (ต้องมีตัวเลข 8-15 หลัก), หมายเหตุ (เช่น แพ้ถั่ว)

ขั้นที่ 6: กด “ยืนยันสั่งซื้อ”
ระบบจะออก เลขออเดอร์ ให้ ควรจดไว้พร้อมเบอร์โทร เพราะใช้ติดตามออเดอร์ได้

3.4 จองโต๊ะ
กรอก ชื่อผู้จอง และ เบอร์โทร
เลือกวันที่ เวลา และ จำนวนที่นั่ง (1-30 ที่)
ใส่ ความต้องการพิเศษ เช่น วันเกิด หรือที่นั่งริมหน้าต่าง
กด “จองโต๊ะ”
ตรวจสอบการจองภายหลังได้โดยกรอก เบอร์โทรที่ใช้จอง ในส่วนด้านล่างของหน้า
3.5 สมาชิกและแต้มสะสม
ไม่ต้องสมัครแยก ระบบสร้างสมาชิกให้อัตโนมัติจากเบอร์โทรที่สั่งอาหาร
กรอก เบอร์โทรที่ใช้สั่งอาหาร เพื่อดูแต้มและประวัติการสั่ง
เกณฑ์แต้ม ได้ 1 แต้มต่อทุก 10 บาทของยอดที่ชำระ (เช่น ยอด 516 บาท ได้ 51 แต้ม) ตามอัตราของระดับสมาชิก
ได้แต้มหลังร้านยืนยันการชำระเงินแล้วเท่านั้น
3.6 ติดตามออเดอร์
กรอก เลขออเดอร์ และ เบอร์โทรที่สั่ง
ดูสถานะปัจจุบัน
สถานะ	ความหมาย
รอตรวจสอบการชำระเงิน	ร้านยังไม่ยืนยันการชำระ
กำลังทำอาหาร	ร้านยืนยันการชำระแล้ว ครัวกำลังทำ
พร้อมรับ/พร้อมเสิร์ฟ	อาหารเสร็จแล้ว
กำลังจัดส่ง	เฉพาะออเดอร์จัดส่ง
สำเร็จ	จบออเดอร์
ยกเลิก	ออเดอร์ถูกปฏิเสธหรือยกเลิก

ออเดอร์แบบรับที่ร้านจะไม่มีขั้นตอน “กำลังจัดส่ง”

แนบ/เปลี่ยนสลิปภายหลัง ทำได้ก่อนร้านยืนยันเท่านั้น แล้วกด “ส่งสลิป” (หากยืนยันแล้วจะเปลี่ยนไม่ได้)
ดาวน์โหลดใบเสร็จ เป็น PDF ขนาด A5 มีตราประทับ PAID แยกราคาก่อน VAT และ VAT 7% หรือเป็น HTML
รีวิว พิมพ์ความคิดเห็นแล้วกด “ส่งรีวิว”
กด “รีเฟรชสถานะ” เพื่อดูสถานะล่าสุด
4. คู่มือสำหรับแอดมิน
4.1 การเข้าสู่ระบบ
เลื่อนลงท้ายหน้าเว็บ กดปุ่ม “🔐 สำหรับพนักงาน”
กรอก รหัสผ่านแอดมิน (ค่าเริ่มต้น admin1234)
กดเข้าสู่ระบบ

ควรเปลี่ยนรหัสก่อนใช้งานจริง ผ่านตัวแปรแวดล้อม

Windows (CMD): set ADMIN_PASSWORD=รหัสใหม่ แล้วรัน streamlit run app.py
Mac/Linux: ADMIN_PASSWORD=รหัสใหม่ streamlit run app.py

หลังเข้าสู่ระบบ ด้านบนจะมีตัวเลขสรุป ได้แก่ ออเดอร์ทั้งหมด, รายได้ (ชำระแล้ว), รอตรวจสลิป, กำลังจัดส่ง และมีปุ่ม ออกจากระบบ

4.2 แท็บต่าง ๆ ในหลังบ้าน

ภาพรวม
สรุปยอดขายวันนี้ รายได้ตามหมวดหมู่ สัดส่วนประเภทออเดอร์ และสัดส่วนวิธีชำระเงิน

ออเดอร์

ออเดอร์ที่รอตรวจจะเปิดไว้ให้ เห็นรูปสลิป ยอดที่ต้องได้รับ และปุ่มยืนยัน/ปฏิเสธ
กรองสถานะ เลือกดูเฉพาะสถานะที่ต้องการ
ยืนยันการชำระ สถานะเปลี่ยนเป็น “กำลังทำอาหาร” ระบบออกเลขใบเสร็จ (เช่น RC000012) และเพิ่มแต้มให้ลูกค้า
ปฏิเสธ ออเดอร์ถูกยกเลิกและ สต็อกถูกคืนอัตโนมัติ
เปลี่ยนสถานะ เลือกสถานะถัดไปแล้วกด “บันทึก” ทำได้หลังยืนยันการชำระเงินเท่านั้น
มอบหมายไรเดอร์ สำหรับออเดอร์จัดส่ง
ดาวน์โหลดสลิป เก็บไฟล์สลิปไว้เป็นหลักฐาน

ครัว

แสดงคิวอาหารที่ต้องทำ กด “ทำเสร็จแล้ว” เมื่อทำเสร็จ และ “รีเฟรชคิว” เพื่อดึงออเดอร์ใหม่

เมนู

เพิ่มเมนู กรอกชื่ออังกฤษ ชื่อไทย หมวดหมู่ ราคา อีโมจิ สต็อก ป้ายกำกับ และรูปอาหาร (ไม่เกิน 800KB) แล้วกด “เพิ่มเมนู”
สต็อก ใส่ -1 หมายถึงไม่จำกัด
ป้ายกำกับ ใส่คำว่า มังสวิรัติ เพื่อขึ้นสัญลักษณ์จุดเขียว หรือ ขายดี เพื่อให้ขึ้นหน้าแรก
แก้ไขเมนู ปรับราคา สต็อก เปลี่ยนรูป และติ๊ก/เอาติ๊ก “เปิดขาย” ได้

จองโต๊ะ

ดูและจัดการรายการจองโต๊ะของลูกค้า

สมาชิก

ดูรายชื่อสมาชิกและแต้ม
ปรับแต้ม (+/-) เลือกสมาชิก ใส่ตัวเลข (บวกเพิ่ม ลบลด) แล้วกด “ปรับแต้ม”

ไรเดอร์

เพิ่มชื่อและเบอร์โทรไรเดอร์ เพื่อมอบหมายงานในแท็บออเดอร์

บัญชี

บันทึกรายจ่าย เลือกหมวด (วัตถุดิบ, ค่าแรง, ค่าเช่า, สาธารณูปโภค, การตลาด, อื่น ๆ) ใส่รายละเอียดและจำนวนเงิน
ลบรายการด้วยเลข id
ส่งออกรายจ่าย/ออเดอร์ เป็นไฟล์ CSV เปิดด้วย Excel ได้

คูปอง

สร้างคูปองโดยกำหนด โค้ด, ลด (%), ขั้นต่ำ (บาท) แล้วกด “บันทึกคูปอง”

รีวิว

ดูความคิดเห็นที่ลูกค้าส่งมา

ตั้งค่า

โลโก้ร้าน อัปโหลดไฟล์ PNG/JPG/WEBP/SVG ไม่เกิน 1MB (แนะนำพื้นโปร่งใส)
ข้อมูลร้าน ชื่อร้าน สโลแกน ที่อยู่ เบอร์โทร เวลาเปิด-ปิด (รูปแบบ 10:00–22:00 น.) ค่าส่ง ฯลฯ
ลิงก์โซเชียล Instagram, Facebook, LINE, TikTok, YouTube, X (ใส่ลิงก์ https://... เว้นว่างคือไม่แสดงไอคอน)
กด “บันทึกการตั้งค่า” ทุกครั้งหลังแก้ไข
5. ขั้นตอนการทำงานประจำวัน (ตัวอย่างการใช้งานจริง)
ลูกค้าสั่งอาหารและแนบสลิป
แอดมินเปิดแท็บ ออเดอร์ ตรวจสลิปเทียบยอดที่ได้รับ
กด ยืนยันการชำระ (ถ้าสลิปไม่ถูกต้องกด ปฏิเสธ)
ครัวเห็นออเดอร์ในแท็บ ครัว ทำอาหารแล้วกด ทำเสร็จแล้ว
ถ้าเป็นออเดอร์จัดส่ง มอบหมาย ไรเดอร์ แล้วเปลี่ยนสถานะเป็น “กำลังจัดส่ง” และ “สำเร็จ”
ลูกค้าติดตามสถานะและดาวน์โหลดใบเสร็จได้ที่หน้า ติดตามออเดอร์
สิ้นวันดูยอดที่แท็บ ภาพรวม และบันทึกรายจ่ายที่แท็บ บัญชี
6. การตั้งค่าในไฟล์ config.py
ค่า	หน้าที่
ADMIN_PASSWORD	รหัสแอดมิน (ตั้งผ่านตัวแปรแวดล้อมได้)
QR_IMAGE	ไฟล์ QR ชำระเงิน (qr.png ในโฟลเดอร์เดียวกับ app.py หรือใส่ลิงก์รูป)
LOGO_SIDE	ตำแหน่งโลโก้ "right" (ขวาบน) หรือ "left" (ซ้ายบน)
VAT_RATE	อัตรา VAT ในใบเสร็จ (ค่าเริ่มต้น 0.07)
TAX_ID	เลขประจำตัวผู้เสียภาษี 13 หลัก ถ้าว่างจะไม่แสดงบนใบเสร็จ

เรื่อง VAT: ราคาในเว็บถือเป็นราคารวม VAT แล้ว ยอดที่ลูกค้าจ่ายจึงไม่เปลี่ยน ใบเสร็จแค่แยกราคาก่อน VAT และ VAT ให้เห็น

เรื่อง QR: ไฟล์ qr.png ที่แนบมาเป็น Thai QR PromptPay ซึ่งเป็นรหัสรับเงินของบัญชีจริง ควรระวังเวลาแชร์โปรเจกต์หรือส่งงานให้ผู้อื่น

7. การทดสอบระบบ
python -m unittest discover -s tests -v

ระบบทดสอบใช้ฐานข้อมูลชั่วคราว ไม่กระทบ restaurant.db จริง ครอบคลุมการสั่งซื้อ คูปอง แต้ม สต็อก การชำระเงิน รายงาน และการตรวจเบอร์โทร/เวลาเปิด-ปิด

8. แก้ปัญหาเบื้องต้น
อาการ	วิธีแก้
ขึ้นว่า Streamlit เก่าเกินไป	pip install -U streamlit
ไม่พบ database.py	วางไฟล์ไว้โฟลเดอร์เดียวกับ app.py และห้ามมีเว้นวรรคในชื่อ
ใบเสร็จ PDF ไม่ขึ้นภาษาไทย	ตรวจว่ามีโฟลเดอร์ fonts/ และติดตั้ง reportlab แล้ว
QR ไม่แสดง	ตรวจว่า qr.png อยู่ข้าง app.py และชื่อตรงกับ QR_IMAGE
สั่งซื้อไม่ได้	ตรวจว่าเบอร์โทรมี 8-15 หลัก สต็อกพอ และสลิปไม่เกิน 3MB
เปลี่ยนสถานะไม่ได้	ต้องกด “ยืนยันการชำระ” ก่อน
เปลี่ยนสลิปไม่ได้	ร้านยืนยันแล้ว ต้องให้แอดมินจัดการ
โค้ดใหม่ไม่ทำงาน	หยุด Streamlit (Ctrl+C) แล้วรันใหม่
